# UMD Tactical Map — Theme + Point Manager

เวอร์ชันนี้ใช้หน้าตาแนวเดียวกับไฟล์ที่ผู้ใช้เลือก แต่ปรับโครงสร้างไม่ให้เมนูซ้อนทับพื้นที่แผนที่

## ฟังก์ชัน

- ค้นหาและกรองหมวดหมู่จุด
- สลับ Atlas / Satellite
- เพิ่มจุดใหม่จากพิกัดหรือคลิกแผนที่
- แก้ไขชื่อ พิกัด และไอคอน
- ลากหมุดขณะแก้ไขเพื่อย้ายตำแหน่ง
- ลบจุด
- บันทึกข้อมูลอัตโนมัติใน Local Storage
- นำเข้า / ส่งออก `data.json`
- คืนค่าข้อมูลต้นฉบับ

## วิธีเปิด

แนะนำให้เปิดโฟลเดอร์ด้วย VS Code และใช้ Live Server เนื่องจากเว็บโหลด Leaflet ภาพแผนที่ และข้อมูลต้นฉบับจากอินเทอร์เน็ต

## การอัปเดตข้อมูลถาวร

ข้อมูลที่แก้จะอยู่ในเบราว์เซอร์เครื่องนั้น กด **ดาวน์โหลด data.json** เพื่อสำรองหรือย้ายข้อมูล และนำเข้าผ่านปุ่ม **นำเข้า** ได้
